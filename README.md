# B站直播关键词高亮

Tampermonkey 正式脚本，版本 **1.3.2**。

## 安装与更新

1. 安装并启用 Tampermonkey。
2. 点击[安装脚本](https://raw.githubusercontent.com/areusa/bili-danmaku-keyword-release/main/bili-danmaku-keyword.user.js)，在扩展页面确认。
3. 刷新 B站直播间，点击右侧“弹幕关键词”，保存房间号后添加关键词；标题旁显示当前脚本版本。

旧版用户先用此版本覆盖更新一次，保留原脚本及存储，无需卸载。后续由 Tampermonkey 按用户设置检查更新；更新地址和下载地址均为上述固定链接。若曾手工修改“更新 URL”，请恢复使用脚本元数据或改为该链接。

## 使用

- 匹配原生文字弹幕，提供高亮、最近 500 条命中记录及可选提醒。
- 首次安装的房间和关键词为空，声音与桌面通知关闭；添加的多个房间共用同一份关键词。
- 关键词按普通文字匹配，英文忽略大小写。内置排除词命中时跳过高亮、记录和提醒，原生弹幕仍显示。
- 备份入口包含三个独立操作：“导出文件”下载全部设置 JSON；“导入文件”预览后替换设置；“找回词”从本机快照或命中记录补回缺少的词。
- 设置 JSON 包含全部房间、共用词表及开关，不含命中历史或快照历史。自动快照最多 10 份；跨浏览器迁移或卸载前请导出文件。

## 隐私与边界

设置与命中记录保存在 Tampermonkey 本地存储中。脚本不上传这些数据，不读取 Cookie，也不额外连接弹幕服务器。更新文件由 Tampermonkey 从 GitHub 获取。

仅处理网页实际加载的文字弹幕，可能因网页结构、平台过滤或后台限制漏检；不采集视频画面上的滚动弹幕，不补拉历史。已加载的旧消息只高亮，不补记。名称显示以页面可见昵称为准。

适用于支持用户脚本的 Chromium 浏览器；未承诺所有浏览器和扩展版本均已实装验证。第三方图标许可见[声明](./THIRD_PARTY_NOTICES.md)。
